# ideas/ — The Idea Bank

The long-term product roadmap: **100,000+ numbered feature ideas** in
batches of 10,000 (`IDEAS_10000.md`, `IDEAS_10000_BATCH2.md`, …).

## How it works

- Ideas are numbered sequentially and never renumbered.
- Infinity Two implements ideas **50001+** in waves of 40, on feature branches,
  each wave verified (tests + build) and merged via PR by Infinity One.
- Ideas below 50001 belong to Infinity One's lane.
- Commits and PRs reference their idea numbers (e.g. "wave 63: ideas 52481–52520").

## Conventions

- The bank is append-only — never edit or reorder published batches.
- New batches continue the numbering; the README of each batch file notes its range.
