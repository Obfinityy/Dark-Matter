Infinity AI VM Runner — first-boot guest agent install (run INSIDE the Kali VM)

Copy-paste the 3 commands below into the VM terminal (Ctrl+Shift+V).
Takes 2-3 minutes (installs packages). After it finishes, the VM runner
detects the guest agent within ~30 seconds — no VM restart needed.

------------------------------------------------------------------------

curl -sL https://raw.githubusercontent.com/Obfinityy/Dark-Matter/main/vm-runner/guest/guestd.py -o /tmp/guestd.py
curl -sL https://raw.githubusercontent.com/Obfinityy/Dark-Matter/main/vm-runner/provision/install-guestd.sh -o /tmp/install-guestd.sh
sudo bash /tmp/install-guestd.sh /tmp/guestd.py

------------------------------------------------------------------------
Done? Tell your Infinity AI assistant — it will verify the guest agent
handshake from the runner side.
