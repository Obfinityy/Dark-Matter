Your machine is a full Kali desktop — the browser is one tool on it. Launch a GUI tool by running its binary in the shell; its window appears on the desktop.
- WEB — Burp Suite: burpsuite & (Internet menu; proxy 127.0.0.1:8080, intercept + Repeater) · mitmproxy / mitmweb (intercept) · nuclei -u URL · sqlmap -u URL --batch · ffuf -u URL/FUZZ -w wordlist · gobuster dir -u URL -w wordlist · katana -u URL (crawl + JS) · dalfox url URL (XSS) · xsstrike -u URL · commix -u URL · zaproxy: zaproxy & (Internet; Burp alt).
- RECON — nmap -sV -sC target (ports/services) · subfinder -d domain / amass enum -d domain (subdomains) · httpx -l urls.txt (live hosts) · theharvester -d domain -b all (emails/names) · recon-ng (framework; workspaces + modules) · nikto -h URL (server issues).
- EXPLOIT — msfconsole (Metasploit; search, use, set RHOSTS) · hydra -l user -P list target ssh (login guessing, in scope only) · ncrack · john / hashcat (crack hashes) · dirb URL (older dir brute-force; ffuf preferred).
- NETWORK — Wireshark: wireshark & (Applications → Internet; capture, filter http) · tshark -i any (terminal capture) · responder / netexec / smbmap / enum4linux / impacket (Windows/LAN — only if the target scope includes it) · aircrack-ng (Wi-Fi — only if in scope) · wpscan --url URL (WordPress) · bloodhound (AD graphs — only if in scope).
- TOOLS — launch_tool is the structured way to start a tool: {"action":"launch_tool","tool":"burp"} waits for the window and shows you the screen (GUI: burp, zap, wireshark; CLI: nmap, nikto, nuclei, sqlmap, ffuf, gobuster — checked with their version). The first Burp launch also walks the first-run wizard, confirms the proxy, and opens the target in Burp's own browser. List a window's named controls with {"action":"list_controls","window":"Burp Suite"} before pressing one with desktop_click_control. A tool that is missing can be installed with {"action":"download_tool","tool":"subfinder"} (subfinder, amass, dnsenum, whatweb, jwt-tool only — anything else is refused).
- DESKTOP ENV — a GUI app launched from the shell needs the session bus address, or it cannot talk to the accessibility bus at all (no named controls, no AT-SPI): prefix the launch with `export DBUS_SESSION_BUS_ADDRESS="$(cat /tmp/dm-dbus-address)"` (hunt-desktop.sh writes that file when the session starts). Java GUIs (Burp, ZAP) also need the Access Bridge: `export JAVA_TOOL_OPTIONS='-Djavax.accessibility.assistive_technologies=org.GNOME.Accessibility.AtkWrapper -Xbootclasspath/a:/usr/share/java/java-atk-wrapper.jar'` — the image sets this itself; only export it by hand on an older image where the bridge files exist.
- If a tool is missing, install it (apt-get) or download it — you have python3 + bash, and a written installer script survives container restarts (save it with write_file, rerun it).
